# ⚡ 扣字神器 V1 (KouZiJi)

基于 **OneBot 11 (NapCat) + Android 原生悬浮窗** 的高频扣字自动化工具。

---

## 🎯 核心功能一览

1. **悬浮球与全功能面板**：
   - 支持桌面任意拖拽、自动吸附。
   - 一键展开/收起面板，不遮挡聊天视野。
   - 明显的 🛑 **紧急停止大按钮**，随时一键刹车。
2. **目标锁定与 @ 开关**：
   - 在 QQ 群内 @ 一次目标成员，程序通过 WebSocket 实时监听**自动捕获并锁定**群号与目标 QQ。
   - “锁定目标”与“是否每条 @ 对方”独立开关控制。
3. **词库系统**：
   - 格式固定为标准 TXT（一行一句），自动过滤空行。
   - 兼容 UTF-8、GBK/ANSI、GB2312 等常见中文编码。
   - 支持多词库导入、选择、删除、预览、去重/留重选项。
4. **发送模式与随机抖动**：
   - 支持 **顺序发送** / **随机发送(本轮不重复)** / **完全随机**。
   - 支持 **从头开始** / **从上次进度继续** / **随机起点**。
   - 发送间隔支持小数秒（如 3.0s），提供**随机抖动**开关与自定义幅度（如 ±0.5s）。
   - 支持**发送数量限制**（如发满 100 条自动停止，或 0 为无限循环）。
5. **高精度秒级自动撤回**：
   - 独立异步撤回队列，自动记录 `message_id`。
   - 发送后指定秒数（如 2.0s）高精度自动撤回，不影响后续发送节奏。
6. **配置自动持久化**：
   - 自动保存用户的词库、间隔、抖动、撤回、@开关等偏好，重启 App 自动恢复。

## 📱 手机端运行架构与使用指南

### 1. 架构示意图
```
[安卓手机 QQ]
     ↑
[NapCat (NTQQ 核心)]  ← (端口 3000 / 3001)
     ↑
[Podroid (Linux 容器)]
     ↑
[扣字神器 悬浮窗 App] (原生 Kotlin)
```

### 2. 手机端使用步骤
1. **启动 NapCat**：在 Podroid 中运行 NapCat 容器（已持久化保存登录凭证，随开随用）。
2. **打开悬浮窗 App**：
   - 首次打开根据提示授予“悬浮窗权限”。
   - 点击“开启悬浮窗”，屏幕边缘出现圆形绿色悬浮球。
3. **锁定目标与扣字**：
   - 在目标 QQ 群内 @ 目标成员一次，悬浮窗自动捕获并显示 `🎯 群: xxx | 目标: xxx`。
   - 点击悬浮球展开面板，点击 **🚀 开始** 即可全自动节奏扣字！

## 🛠️ 构建与编译说明 (无需 Android Studio)

### 方式 1：GitHub Actions 自动云端编译 (最推荐)
项目已内置 `.github/workflows/build_apk.yml`，只要把代码推送到 GitHub 仓库，GitHub 就会自动在云端编译出最新的 `app-debug.apk` 安装包，在 Actions 页面点击直接下载即可。

### 方式 2：本地命令行构建
在安装了 Java 环境的电脑终端执行：
```bash
./gradlew assembleDebug
```
编译产物位于：`app/build/outputs/apk/debug/app-debug.apk`。

### 方式 3：电脑端直接运行测试
电脑端直接运行 Python 核心脚本：
```bash
python kouzi_desktop.py
```
